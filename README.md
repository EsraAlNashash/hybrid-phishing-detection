# Phishing Detection with Hybrid Feature Selection

This project implements a machine learning pipeline to detect phishing websites using a hybrid feature selection approach. It combines Mutual Information, Recursive Feature Elimination (RFE), and Extra Trees Classifier (ETC) to identify the most relevant features. The filtered data is then used to evaluate multiple classifiers: Artificial Neural Network (ANN), Decision Tree (DT), K-Nearest Neighbors (KNN), Support Vector Machine (SVM), and Logistic Regression (LR).
